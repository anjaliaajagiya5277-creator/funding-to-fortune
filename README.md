# 🚀 Funding to Fortune

Funding to Fortune is a machine learning project that analyzes startup funding data to predict the future success of businesses. The goal of this project is to help investors, entrepreneurs, and analysts make data-driven decisions by identifying key factors that influence startup growth.

## 📌 Project Overview

This project uses historical startup funding data to build predictive models that estimate whether a startup has strong potential for success. The system performs data preprocessing, feature engineering, model training, and prediction, providing insights into funding patterns and business outcomes.

## ✨ Features

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Machine Learning model training
- Prediction using trained models
- Saved models using Pickle (.pkl)
- Simple Python-based application for predictions

## 🛠️ Technologies Used

- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Jupyter Notebook  

## 📂 Project Structure

- `funding_to_fortune.ipynb` – Model development notebook  
- `startup_data.csv` – Dataset  
- `app.py` – Prediction application  
- `.pkl` files – Trained machine learning models  
- `README.md` – Project documentation
